# Jyz

Generated by [JfYu.Template](https://github.com/jfwangncs/JfYu.Template)'s quick-start script.

## Repository Layout

```text
  src/api/                 # ASP.NET Core 10 Web API backend (generated by dotnet new JfYuWebApi)
  src/web/                 # Vue 3 + TypeScript + Vite monorepo frontend
```

## Quick Start

### Backend

```bash
cd src/api
dotnet restore
pwsh reset-migrations.ps1   # generates the first EF Core migration for PostgreSQL and applies it
dotnet run
```

Open `https://localhost:{port}/scalar/v1` to explore the API.

### Frontend

```bash
cd src/web
pnpm install
pnpm --filter @vben/web-antd dev
```

Open the URL printed by Vite (default `http://localhost:5666`).
